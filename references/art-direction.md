# 廷根项目美术方向基准

机器权威 Profile：`profiles/tingen_pixel_v3_hd/profile.json`。本页是给人阅读的解释；发生冲突时，以机器 Profile 和具体任务合同为准。

## 通用文件规则

- 格式：PNG，原生 1× 像素制作；运行时不提交预先放大图。
- Alpha 只能是 0 或 255。
- 禁止抗锯齿、模糊边缘、平滑渐变、分数缩放和半像素坐标。
- `_4x.png` 只用于 Nearest 整数预览，不是运行时素材。
- 白天主光固定来自左上，暗面落向右下。
- 颜色必须来自廷根登记色板，并按石材、木材、玻璃、铁艺等材质子色板声明。
- 生成式图片只能作为 HD 参考，禁止缩小、量化或自动 fit 后直接交付。

当前仓库只有从 Mango Master + Loen 映射出的临时廷根色表，状态为 `provisional_pending_project_palette_import`。在用户提供并批准完整廷根 RGB 登记表前，验证器会阻止 `runtime_ready`，不能把临时映射冒充正式色表。

## 原生尺寸

| 资产类别 | 原生尺寸/策略 |
|---|---|
| 标准地形瓦片 | 64×64 |
| 材质审核样板 | 192×192，由同一 64×64 原样平铺 3×3 |
| 常规人物单帧 | 64×96 |
| 人物脚底锚点 | `(32,96)`，`canvas_boundary` |
| 普通立面组件 | 96–192px，任务固定精确尺寸，16px 对齐 |
| 建筑组合 | 384–1024px，任务固定精确尺寸 |
| 地标组合 | 1024–2048px，任务固定精确尺寸 |
| 市政广场市政厅 | 1024–1536px 专项范围，任务固定精确尺寸 |
| UI、VFX、道具 | 必须由专项任务合同给出尺寸和锚点，禁止猜测 |

范围不是导出器自由 fit 的授权。任务开始时必须把一个精确 `[width,height]` 写入合同，之后所有帧、层、变体保持不变。

## 调色板与材质

- 64×64 地形通常 10–16 个不透明登记色。
- 普通立面通常 16–24 个不透明登记色。
- 人物默认不超过 24 个登记色；专项合同可以更严。
- 透明像素不计颜色数。
- 禁止对复合资产执行全项目最近色量化；正式 1× 资产必须由像素画师按材质子色板落色。
- `assets/palettes/tingen-materials.json` 是当前材质子色板注册表；其 provisional 状态是发布阻断项。

`palette_remap.py` 仅用于候选参考和诊断，不能把 HD 生成图“洗成色板”后视为正式像素资产。

## 构图与投影

- 正交，无透视汇聚；北向朝上。
- 道路、地块和建筑基线只允许 0°/90°。
- 规划连接只允许精确 45°。
- 公共建筑门洞净宽至少 64px；专项合同可以更宽。
- 门、碰撞、遮挡和导航是独立工程数据，不能从 PNG Alpha 自动推断。

## 人物与纸娃娃

所有人物层和动画帧共用 64×96 画布及 `(32,96)` 画布边界锚点。正式 1× 资产不做 bbox/fit；base/outfit/hair/acc 直接在同一坐标系绘制。

- z-order：`base → outfit → hair → acc`。
- 所有方向和所有动作帧都保持相同画布、锚点与整数坐标。
- 层重做时必须在完整组上重新跑叠层和轮廓审计，不能只验证单层。
- 动画帧数、foot lock 和四向规则见 `references/character-motion-standard.md`。

## Godot 导入

- Texture Filter：Nearest。
- Mipmaps：关闭。
- 压缩：Lossless 或项目批准的像素安全模式。
- Repeat：只对任务合同声明可平铺的纹理开启。
- 节点位置和缩放使用整数值；禁止用分数缩放掩盖尺寸问题。
- 图片审计通过不等于 `runtime_ready`；还要在项目内验证入口、碰撞、导航和同屏比例。

## 标准交付

```text
<asset_id>/
├─ <asset_name>_1x.png
├─ <asset_name>_4x.png
├─ manifest.json
├─ audit.json
├─ source_reference.json
└─ import_contract.json
```

使用 `scripts/package_asset.py` 创建目录，使用 `scripts/validate_delivery.py` 独立复核。打包器不会缩放 `_1x.png`，也不会从 Alpha 推断任何运行时数据。

## 时段

白昼资产遵循固定左上主光。黄昏、夜晚、雾天优先由 Godot 的项目级光照/调色系统处理；如果专项合同要求烘焙时段变体，仍须遵守硬 Alpha 和登记色板，不能提交半透明软雾 PNG。
