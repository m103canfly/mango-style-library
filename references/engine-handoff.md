# 从效果图到引擎：资产落地路径

AI 生成图是概念稿/重绘参考，不能直接进引擎（自带水印、非逐格原生像素、无锚点信息）。用户问"怎么用到游戏里"时按此路径回答。

## 三步路径

1. **引擎选型**：俯视 2D 生活模拟/RPG 首选 Godot 4（TileMap 层 + Y-Sort 原生支持、免费轻量）；Unity 备选；RPG Maker MZ 搭城最快但 HUD/灯光自由度低。
2. **素材重绘拆分**（像素画师或 Aseprite，以本 skill 产出的图为参考）：
   - 地面 TileSet：32×32 一组，每材质 4-6 块错缝变体防重复感，做 terrain 自动铺边
   - 建筑/大物件 sprite：整图 + 锚点，不按 tile 切（喷泉底座与水层分离、建筑立面整幅）
   - 角色：4 方向 × 3 帧行走（32×48/帧），同方向帧先共享 transform 导出，再按 `character-motion-standard.md` 与 motion audit 修形
   - 动画条：水波 4-6 帧循环、炊烟、灯焰闪烁
   - UI：面板/按钮按 9-patch 切框，中心留空叠程序文字
3. **场景搭建**（Godot 节点结构）：地面 TileMapLayer + 装饰层 + 不可见碰撞层 + 开了 `y_sort_enabled` 的 YSort 父节点（建筑/NPC/玩家按脚底 y 自动前后遮挡）+ 灯光层（煤气灯 PointLight2D 或预烘焙光晕 sprite，白天基调用 CanvasModulate 罩灰蓝）+ CanvasLayer HUD。交互点放 Area2D 弹「E 交互」提示。

## 各类别拆分要点速查

| 类别 | 拆分规格 | 注意 |
|---|---|---|
| 建筑立面 | 整幅 sprite，底边中点为锚点 | 门窗若要单独开关，拆成独立小 sprite 叠层 |
| 地面 tile | 32×32，4-6 变体 | AI 图不对拼，取中心区裁切后人工做无缝 |
| 家具 | 整幅 sprite，脚底锚点 | 桌椅组合拆两件，方便 Y-Sort 遮挡 |
| 树木 | 树冠/树干两层分离 | 角色走到树后时树冠半透或遮顶 |
| 角色 | 32×48/帧，4方向×3帧 | 以 sprite sheet 草图为动作参考重绘 |
| UI | 9-patch 边框 + 独立图标 | AI 不出文字，全部程序叠字 |

## 拼合整合六件套（2026-08 街区切片实测：缺了就"单个好看、拼起来突兀"）

素材直接平铺拼合必然生硬，无论 PIL 模拟还是 Godot 实机，都必须补这六层整合：

1. **接触阴影**：每个落地物底部画半透明椭圆软影（宽≈1.1-1.3×物宽，高≈0.2×宽，alpha 60-85，高斯模糊 3-4px），建筑底部再加 AO 压暗条——没有投影的素材就是"贴纸"
2. **边缘过渡**：路面/人行道/草地之间加路缘石条（石板压暗 ×0.7 + 顶部亮线），纹理不许硬切
3. **tile 变体**：同一 tile 至少 4 变体（水平翻转/旋转180/压暗×0.9/原始）伪随机混铺，杀摩尔纹格子感
4. **全球罩色**：全场统一降饱和（×0.93）+ 暖色罩（#F0E0C0 约 7%），模拟 CanvasModulate，把各自烘焙光照的素材焊进同一时段
5. **破对称**：树/灯/井盖等距对称 = 展示架；错开间距、成组聚集才有街道感
6. **前景框景**：画面底边放被裁切的前景元素（草地、树冠、栅栏），瞬间建立景深，消除"空广场"感

另：纯正面立面建筑立在俯视地面上天然有"纸板房"感，六件套只能缓解不能根除；要做拼合 mockup 可给建筑出 3/4 俯视版本（见 architecture-tiles 修方）。

## 与规划图的衔接

tile 级规划底稿可导出为 Tiled `.tmx`/JSON 或 CSV 坐标表，一键导入 Godot/Unity 作为摆好物件的场景骨架，之后替换正式美术素材。
